Configuration lives in two files.

Everything except the credential goes in `$site/etc/@PLUGIN@.config`:

```ini
[github]
	apiUrl = https://api.github.com

[archiver]
	skipAutogenerated = true
	skipPrivate = true

[sweep]
	interval = 5 minutes
	startTime = 00:00
	lookbackMinutes = 180
	limit = 500

[project "myproject"]
	owner = TheoGoudout
	repo = myproject
	branchPrefix = gerrit-archive
	branch = master
```

`[sweep] interval` uses Gerrit's standard schedule syntax, the same as
`gc.interval`. **Set it.** Without it the plugin runs on events only, and a
missed event is never recovered.

`[project "name"]` maps one Gerrit project onto one GitHub repository. Repeat
the section per project. `branch` is repeatable and restricts which branches
are archived; all branches are archived when it is absent.

The GitHub token goes in `$site/etc/secure.config`, never in the file above:

```ini
[plugin "@PLUGIN@"]
	githubToken = ghp_...
```

It needs `contents: write` and `pull_requests: write` on each destination
repository, and nothing else. Gerrit's config layer resolves secure values
transparently, and the plugin re-reads them on each use, so rotating the token
does not require a restart.
